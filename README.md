# 星喚の塔（試作版・第5版）

滅びかけた世界の「待機室」で、記憶をなくした英雄たちを導き、100階の塔を制覇して世界を救うゲームです。
プレイヤーは英雄たちの「マスター」。ゲームの中で映すのは待機室だけで、建物や英雄をタップしてすべての機能に入ります。

名前・キャラクター・世界観・絵はオリジナルです（絵はすべてコードで描いています）。

公開ページ: https://gizora.github.io/seikan-tower/

## 世界
- 待機室の名前（カタカナ5文字ほど・始めたときに決まる）が、そのまま滅びかけた世界の名前です。塔の100階を制覇すると世界を救えます。
- 英雄はその世界の人々。何も覚えていませんが、★を上げるたびに記憶がよみがえります。
- 召喚のたびに、名前・見た目・職業・性格・才能・記憶がすべて違う英雄が生まれます。**同じ英雄は二度と出ません**（まれに、手作りの特別な英雄が一度だけ現れます）。

## 待機室（ホーム）
- 城壁に囲まれた敷地を、立体の世界とドット絵の英雄で描いています（光・影・霧・光のにじみ・ミニチュア風のぼかし）。時間帯は現実の時計に合わせて昼・夕方・夜に変わります。
- ドラッグで見回す・ピンチやホイールで寄る・2本指でひねって回す（右下のボタンでも可）。
- **待機室の時間は現実と同じ速さで進みます**。閉じていた間も最大4時間ぶん進み、開くと「留守のあいだに」で起きたことがわかります。
- 英雄は自分の考えで過ごします（訓練所で訓練する・広場で過ごす・宿舎で休む・歩き回る）。頭の上のアイコンで、何をしているかがわかります。
- 建物: 🌀 次元の門（塔へ・召喚）/ 🛏️ 宿舎（英雄の一覧）/ ⛲ 広場（提案・喧嘩・仲・出来事）/ 🎯 訓練所（才能と訓練の様子）/ 🗺️ 戦略室（編成と作戦）/ ⚗️ 合成所 / ⚔️ 武器倉庫 / 🧪 錬金場。訓練所と広場は最初から建っています。

### 才能と訓練・成長
- 英雄には能力（体力・攻撃・防御・速さ）ごとに才能（— / C / B / A / S）があります。
- 訓練所で訓練すると、才能のある能力が少しずつ伸びます。**才能のない能力（—）は伸びません**。伸ばせる上限は才能と★で決まります。
- 塔の中で戦うと、使った能力が伸びます（攻撃した英雄は攻撃、攻撃を受けた英雄は体力と防御、たくさん動いた英雄は速さ）。

### 仲・喧嘩・殺し合い
- 英雄どうしには仲（-100〜100）があり、性格の相性や一緒に過ごした時間で変わります。
- 仲が悪いと喧嘩が起きます（「〜と〜が喧嘩しています」）。タップして**仲裁**します（どちらかの味方をする / 二人を叱って仲直りさせる）。
- 仲裁しないまま時間がたつと、けが人が出ます。仲がとても悪いと**殺し合い**になり、英雄が失われます。待機室の平和を保つのもマスターの役目です。
- 仲がとても悪い英雄どうしを同じ編成にすると、塔の中で**裏切る**ことがあります。

### 提案
英雄の声は聞こえません。英雄は「〜が〜を提案しています」で、マスターに提案します。受けると信頼度が上がり、断ると少し下がります。

## 塔の中（マスターが見ている映像）
- 階ごとに広いマップがあり、壁・水・草むら（隠れるとダメージが減る）・高台（上から攻撃するとダメージが増え、弓や魔法が遠くまで届く）があります。
- **任務は階ごとに違い、最初はわかりません**。英雄が NPC から話を聞いたり、石碑を調べたりすると判明します（討伐・回収・護衛・探索・生存・主の討伐）。任務を果たすと出口が開き、出口にたどり着けば勝ちです。
- 英雄は自分で探索し、戦い、危なければ逃げます。英雄の一覧で、誰が何をしているか（探索・攻撃・回復・防御・逃走・**サボり**など）がわかります。
- 英雄をタップすると命令できます: ⚔️ 狙え / ✦ スキル / 🛡️ 守れ / 📍 ここへ / 💨 逃げろ。「指示」をオンにすると、地面をタップして全員の行き先を決められます（オフなら英雄まかせ）。信頼度が低い英雄は従わないことがあります。
- 様子はメッセージでわかります（「〜が恐怖状態、能力値が30%減少」「〜が出血状態、体力が減少中」など）。
- 最後に **MVP** と、レベルや能力が上がった英雄がわかります。倒れた英雄は二度と戻りません。

## 画面の向き
縦でも横でも遊べます。横にすると、塔の中では英雄の一覧が左に並びます。

## 起動のしかた
- **PC で試す**: `index.html` をブラウザで開くだけで遊べます（WebGL が使えるブラウザ）。
- **スマホ**: 公開ページを開き、ホーム画面に追加するとアプリのように遊べます（オフラインでも可）。ネットにつながっていれば、開くたびに最新版になります。
- 進み具合はブラウザに自動で保存されます。前の版の保存データも引き継げます（そのときの英雄はそのまま残り、訓練所と広場は建った状態になります）。

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` / `css/style.css` | 画面の骨組みと見た目（縦・横の両方） |
| `js/data.js` | 職業・手作りの英雄・敵・塔100階・施設・装備・薬・状態・提案・任務・才能・仲の決まり |
| `js/herogen.js` | 英雄を自動で作る（名前・見た目・才能・スキル・記憶）と、世界の名前 |
| `js/battle.js` | 塔の中のしくみ（マップ・経路・任務・英雄の考え・戦闘・命令・提案・裏切り・MVP）。画面に依存せず Node でも動く |
| `js/game.js` | 保存・召喚・育成・待機室の時間・訓練・仲・喧嘩・施設・報酬 |
| `js/sprites.js` | ドット絵をコードで描く（英雄は 32×64 ドット・斜め前から見た姿・歩く/攻撃/詠唱などのポーズ） |
| `js/world3d.js` | 立体の世界の共通部分（光・カメラ・後処理・ドット絵の板・pixelfx のエフェクト） |
| `js/room.js` | 待機室（立体） |
| `js/field.js` | 塔の中の映像（立体） |
| `js/ui.js` | 画面の表示と操作 |
| `js/lib/` | 外部ライブラリ（下記） |
| `manifest.webmanifest`, `sw.js`, `icons/` | ホーム画面に追加（PWA）とオフライン対応 |

## 使っている外部ライブラリ（どちらも MIT ライセンス・無料）
- **three.js r147**（立体の表示と、光のにじみ・ぼかしなどの後処理）https://github.com/mrdoob/three.js
- **pixelfx**（ドット絵のエフェクト。必要なものだけを、ふつうの `<script>` で読めるようにまとめて使っている）https://github.com/patch-gg/pixelfx

ライセンスの全文は `js/lib/LICENSES.md` にあります。
