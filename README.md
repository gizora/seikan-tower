# 星喚の塔（試作版・第3版）

滅んだ世界から来た英雄を集め、作戦と命令で導いて塔に挑む、スマホ向けのオート戦闘ゲームです。
プレイヤーは英雄たちを導く「マスター」です。戦闘中、英雄は**それぞれの性格と、マスターへの信頼に合わせて自分で考えて**動きます。マスターは**作戦**で方針を伝え、戦闘中は**英雄をタップして命令**を出せます。

名前・キャラクター・世界観・絵はすべてオリジナルです。

公開ページ: https://gizora.github.io/seikan-tower/

## 物語
塔の5階ごとに、ひとつの**滅んだ世界**が眠っています（緑の王国エルデ・骨の帝国ネクロア・氷の国フロスベル・獣の大陸ガルム・影の都ノクス・星の海アストラ）。ボスを倒すと、その世界を救えます。
英雄たちは滅んだ世界の人々ですが、**何も覚えていません**。★を上げるたびに、少しずつ記憶を取り戻していきます。

## 遊び方

1. **待機所**（ホーム）: 英雄たちが暮らす建物を横から見た断面図。施設を建てると階が増える。英雄は階段で階を行き来し、本を読み、訓練し、眠り、話し合う。英雄をタップすると話しかけられる（戦闘ごとに1回、信頼度 +6）。部屋をタップすると施設の画面が開く
2. **召喚**（次元の門）: 💎 召喚石で英雄を呼ぶ（1回 100 / 10回 1,000 で★2以上が1体確定 / 60回までに必ず★3）。すでにいる英雄が出ると ✦ 星の欠片になる
3. **編成**: 5人までのパーティーを組み、前衛・後衛に置く
4. **作戦**: 作戦 / 撤退 / 狙う敵 / 回復の目安 / スキル。戦略室のレベルで使える作戦が増える
5. **塔**: 30階（6つの世界 × 5階）。5階ごとにボス。勝つと経験値・金貨・星の欠片、初クリアでは召喚石ももらえる

### 戦闘中の命令
戦闘中に英雄をタップすると、命令を出せます。

| 命令 | 効果 |
|---|---|
| ⚔️ この敵を狙え | 選んだ敵を優先して攻撃する（倒すまで、または4回の行動まで） |
| ✦ スキルを使え | 次の行動ですぐにスキルを使う（「温存」の作戦でも使う） |
| 🛡️ 守りを固めろ | すぐに守りの構えをとり、次の行動でも守る |

- 命令すると**命令ゲージ**が空になり、決まった数の行動のあいだ次の命令は出せません（戦略室で短くなる: 6 → 2 行動）。
- 命令を選んでいる間、戦闘はゆっくり進みます。
- **信頼度が 45 未満の英雄は、命令に従わないことがあります。**

### 待機所の施設
建てる・レベルを上げるには金貨が必要です（Lv2 以上は、塔の決まった階をクリアしていることも必要）。施設を建てると、待機所に階が増えます。

| 施設 | 最初 | 効果 |
|---|---|---|
| 🌀 次元の門 | Lv1 | 召喚の ★3 の確率（5% → 9%）。塔への入口 |
| 🛏️ 宿舎 | Lv1 | 暮らせる英雄の数（8 → 20人）。いっぱいのときに出た新しい英雄は帰ってしまう（星の欠片を残す） |
| 🎯 訓練所 | なし | 編成に入っていない英雄も、戦闘のたびに経験値をもらえる（20% → 80%） |
| 🗺️ 戦略室 | なし | 使える作戦が増える（Lv1 撤退 / Lv2 狙う敵 / Lv3 回復の目安 / Lv4 スキル / Lv5 英雄ごとの狙う敵）。命令ゲージが短くなる |

### 世界の難易度
始めたときに、マスターごとにランダムで決まります。

| 難易度 | 出やすさ | 敵の強さ | 報酬 |
|---|---|---|---|
| 穏やかな世界 | 20% | ×0.9 | ×0.9 |
| ふつうの世界 | 45% | ×1.0 | ×1.0 |
| 過酷な世界 | 25% | ×1.1 | ×1.25 |
| 地獄の世界 | 10% | ×1.2 | ×1.5 |

「データを消して最初から」でやり直すと、難易度と待機所の名前も決め直されます。

### このゲームの決まり
- **永久ロスト**: 塔で倒れた英雄は二度と戻らない。名前は待機所の慰霊碑に刻まれ、仲間たちのマスターへの信頼が下がる。危ないときは「撤退」ボタンか、作戦の「撤退」で逃げられる。
- **信頼度**（0〜100）: 45 未満の英雄は、作戦や命令を無視することがある。60 以上で能力 +5%、90 以上で +10%。話す・一緒に勝つ・昇級・故郷の世界を救うと上がり、負ける・仲間を失うと下がる。
- **★の昇級と記憶**: 最大レベルになったら、星の欠片で★を上げられる（★1 → ★5）。★を上げるたびに記憶が1つよみがえる（★3 で故郷を思い出す）。★3 と ★5 で特性の枠が増える。
- **特性**（10種類・Lv1〜3）と**送り出す・合成**: 英雄を故郷へ送り出すと星の欠片がもらえ、特性を1つほかの英雄に受け継がせられる（同じ特性ならレベルが上がる）。
- **性格**（5種類）: 忠実 / 勇敢 / 慎重 / 気まぐれ / 仲間思い。同じ作戦でも動き方や命令への返事が違う。

## 起動のしかた

- **PC で試す**: `index.html` をブラウザで開くだけで遊べます。
- **スマホ**: 公開ページを開き、Android（Chrome）は「ホーム画面に追加 / アプリをインストール」、iPhone（Safari）は共有 →「ホーム画面に追加」。一度開くとオフラインでも遊べます。ホーム画面に追加したあとも、ネットにつながっていれば開くたびに最新版になります。
- 進み具合はブラウザ（localStorage）に自動で保存されます。前の版の保存データはそのまま引き継げます（難易度は「ふつう」、宿舎は今の人数が暮らせるレベル、戦略室は進み具合に合わせたレベルになります）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目 |
| `js/data.js` | 英雄17体（見た目・故郷・記憶）・敵・塔30階・滅んだ世界・難易度・施設・特性・作戦・命令・会話 |
| `js/battle.js` | オート戦闘（英雄の思考・信頼度・特性・ボスの特徴・命令）。Node でもシミュレーションできる |
| `js/sprites.js` | ドット絵をコードで描く（英雄は人の頭身 24×48 ドット。体格・背丈・服・髪型・飾り・武器の組み合わせ） |
| `js/room.js` | 待機所（建物の断面図。施設ごとの階と、暮らす英雄たち） |
| `js/game.js` | 保存・ガチャ・育成・昇級・記憶・信頼度・施設・難易度・送り出し・永久ロスト・報酬 |
| `js/ui.js` | 画面の表示と操作、戦闘の演出と命令 |
| `manifest.webmanifest`, `sw.js`, `icons/` | ホーム画面に追加（PWA）とオフライン対応 |

外部ライブラリ・画像素材は使っていません（絵はすべてコードで描いています）。
