# 星喚の塔（試作版）

ガチャで英雄を集めて、作戦を決めて塔に挑む、スマホ向けのオート戦闘ゲームです。
プレイヤーは英雄たちを導く「マスター」です。戦闘中、英雄は**それぞれの性格に合わせて自分で考えて**動きます。プレイヤーが決めるのは**編成と作戦**だけです。

名前・キャラクター・世界観はすべてオリジナルです。

## 遊び方

1. **召喚**: 💎 召喚石で英雄を呼ぶ（1回 100 / 10回 1,000 で★2以上が1体確定 / 60回までに必ず★3）
2. **編成**: 5人までのパーティーを組み、それぞれを前衛・後衛に置く（前衛は狙われやすい）
3. **作戦**: 4つの方針を決める（戦闘中も変えられる）
   - 作戦: 攻撃重視 / バランス / 守り重視
   - 狙う敵: 弱った敵 / 強い敵 / 前の敵 / おまかせ（性格で決める）
   - 回復の目安: HP 30% / 50% / 70%
   - スキル: すぐ使う / 温存（ボス戦かピンチまで）
4. **塔**: 10階まで。勝つと経験値と金貨、初めてクリアした階では召喚石がもらえる。負けても経験値が少しもらえ、ヒントが出る
5. **育成**: 戦闘の経験値か、英雄画面の「訓練」（金貨）でレベルを上げる。同じ英雄が出ると「覚醒」して強くなる

### 英雄が自分で考えること
- **性格**（5種類）: 忠実（作戦どおり）/ 勇敢（守らない）/ 慎重（早めに守る）/ 気まぐれ（ときどき好きな敵を狙う）/ 仲間思い（ピンチなら温存中でもスキルで助ける）
- 回復役は仲間の HP を見て回復するかどうかを決め、戦士は仲間が傷ついたら敵の攻撃を引きつけます。考えたことは吹き出しで表示されます。

### ボスの特徴
- 5階 ゴブリンキング: 手下を呼び続ける
- 10階 骨の竜: 行動するたびに攻撃力が上がる

階によって合う作戦が変わるように調整しました（シミュレーションでは、同じ編成でも作戦によって10階の勝率が 0%〜82% まで変わります）。

## 起動のしかた

- **PC で試す**: `index.html` をブラウザで開くだけで遊べます（インストール不要）。
- **スマホで遊ぶ・ホーム画面に追加する**: HTTPS のサーバーに置く必要があります（例: GitHub Pages）。
  - スマホのブラウザで開き、Android（Chrome）は「ホーム画面に追加 / アプリをインストール」、iPhone（Safari）は共有ボタン →「ホーム画面に追加」。
  - 一度開くとファイルが保存され、オフラインでも遊べます。
  - `file://` で開いたときは、ホーム画面への追加の機能（manifest と service worker）は自動でオフになります（エラーを出さないため）。
- 進み具合はブラウザ（localStorage）に自動で保存されます。英雄画面の「データを消して最初から」で消せます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目 |
| `js/data.js` | 英雄 17 体・敵・塔 10 階・作戦・ガチャの数値 |
| `js/battle.js` | オート戦闘のしくみ（英雄の思考・ダメージ計算）。画面に依存しないので Node でもシミュレーションできる |
| `js/game.js` | 保存・ガチャ・育成・報酬 |
| `js/ui.js` | 画面の表示と操作、戦闘の演出 |
| `manifest.webmanifest`, `sw.js`, `icons/` | ホーム画面に追加（PWA）とオフライン対応 |
| `tests/scenario.json` | ブラウザでの動作確認シナリオ（`check-app.js` 用） |
| `tests/core-test.js` | ガチャ・育成・報酬・保存のテスト（`node tests/core-test.js`） |
| `tests/sim.js` | バランス確認用のシミュレーション（`node tests/sim.js`、数分かかる） |

外部ライブラリは使っていません。キャラクターは絵文字で表示しているので、端末によって見た目が少し変わります。

## 判断したこと

- 仮タイトルは「星喚の塔」。
- 英雄が倒れても失わない（いなくならない）ことにした。試作版では負けてもやり直しやすくするため。
- 課金の仕組みはない。召喚石は塔の初クリアでだけ手に入る（最初の分と合わせて約 55 回分）。
- キャラクターの絵は絵文字で代用した。絵を用意すれば差し替えられる。

## 残っている課題

- 実機のスマホでの「ホーム画面に追加」は、まだ確かめていない（HTTPS で公開してから確認が必要）。
- 遊べるのは 10 階まで。英雄の装備・物語・効果音はまだない。
- バランスはシミュレーションで調整したもので、実際に遊んだ手応えでの調整はこれから。
