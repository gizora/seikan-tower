# 星喚の塔（試作版・第4版）

記憶をなくした英雄たちを導き、100階の塔を制覇して世界を救う、スマホ向けのオート戦闘ゲームです。
プレイヤーは英雄たちの「マスター」。戦闘は英雄まかせで、マスターは塔の中の映像を見ながら、作戦と命令で英雄を導きます。

名前・キャラクター・世界観・絵はすべてオリジナルです（絵はすべてコードで描いています）。

公開ページ: https://gizora.github.io/seikan-tower/

## 物語
滅びかけた世界「エテルナ」。塔の**100階**を制覇すれば、世界を救えます（ゲームクリア）。
英雄たちはこの世界の人々ですが、何も覚えていません。★を上げるたびに記憶がよみがえり、★3 で故郷（エルデ・ネクロア・フロスベル・ガルム・ノクス・アストラの6地方）を思い出します。
塔は10階ごとの区域に分かれ、区域の最後の階にボスがいます。区域のボスを倒すと、その地方の出身の英雄の信頼度が上がります。

## 遊び方
- **待機所**（ホーム）: 城壁に囲まれた敷地を斜め上から見た絵。英雄が施設のあいだを歩き回り、頭の上のアイコンで何をしているか（眠る・訓練・読書など）がわかる。英雄や施設をタップできる。
- **召喚**: 💎 で英雄を呼ぶ（1回 100 / 10回 1,000・★2以上1体確定 / 60回までに必ず★3）。同じ英雄は ✦ 星の欠片になる。
- **編成**: 5人まで。前衛・後衛を切り替えられる。作戦は戦略室のレベルで増える。
- **塔**: 100階（区域10 × 10階）。勝つと経験値・金貨・星の欠片、初クリアでは召喚石も。

### 英雄の声は聞こえない
英雄の声はマスターには聞こえません。様子はメッセージでわかります。
- 「〜が恐怖状態、能力値が30%減少」: 仲間が倒れたときや、ボスを前にしたときなど。恐怖のあいだは立ちすくむこともある。
- 「〜が出血状態、体力が減少中」: 一部の敵の攻撃や会心の一撃で。自分の番のたびに HP が減る。
- 「〜がサボっている」: 信頼度がとても低い英雄は、戦わずにサボることがある。

### 提案
英雄はマスターに提案をします。「受ける」と信頼度が上がり、「断る」と少し下がります。
- 待機所（戦闘のあとなど）: 特訓・次の戦いへの参加・作戦の変更・宴会・薬の補充・装備の新調
- 戦闘中: 撤退・作戦「守り重視」・ボスへの集中攻撃

### 戦闘の映像
英雄と敵が戦う様子を、マスターが見ています。英雄の一覧には、それぞれが今何をしているか（攻撃・防御・回復・サボり・立ちすくむ・戦闘不能）と、状態（恐怖・出血など）が出ます。
- 英雄をタップすると命令できる: ⚔️ 狙え（映像の敵をタップ）/ ✦ スキル / 🛡️ 守れ。命令すると命令ゲージが空になる。
- 戦闘の終わりに **MVP** が決まり（信頼度と経験値が少し多くもらえる）、誰のレベルが上がったかがわかる。

### 待機所の施設（8つ）
| 施設 | 効果 |
|---|---|
| 🌀 次元の門 | 塔への入口。★3 の出る確率が上がる |
| 🛏️ 宿舎 | 暮らせる英雄の数（8 → 20人） |
| ⛲ 広場 | 提案が出やすくなり、ためておける数が増える |
| 🎯 訓練所 | 編成に入っていない英雄も経験値をもらえる |
| 🗺️ 戦略室 | 使える作戦が増え（撤退 → 狙う敵 → 回復の目安 → スキル → 英雄ごとの狙い）、命令ゲージが短くなる |
| ⚗️ 合成所 | 英雄を送り出すとき、特性を受け継がせられる。費用が下がる |
| ⚔️ 武器倉庫 | 装備（武器・防具）を作る。鉄 → 鋼 → 銀 → ミスリル → 星鉄。倒れた英雄の装備は一緒に失われる |
| 🧪 錬金場 | 薬を作る（止血薬・鎮静薬・回復薬）。戦闘で英雄が自分で使う |

建てる・レベルを上げるには金貨が必要（Lv2 以上は決まった階のクリアも必要）。

### このゲームの決まり
- **永久ロスト**: 塔で倒れた英雄は二度と戻らない。危ないときは「撤退」。
- **信頼度**: 45 未満の英雄は作戦や命令に従わないことがあり、とても低いとサボる。
- **世界の難易度**: 始めたときにランダムで決まる（穏やか / ふつう / 過酷 / 地獄）。地獄ほど敵が強く、報酬が多い。

## 画面の向き
縦でも横でも遊べます。横にすると、メニューが左に縦に並び、戦闘は左に英雄の一覧・右に映像になります。

## 起動のしかた
- **PC で試す**: `index.html` をブラウザで開くだけで遊べます。
- **スマホ**: 公開ページを開き、ホーム画面に追加すると、アプリのように遊べます（オフラインでも可）。追加したあとも、ネットにつながっていれば開くたびに最新版になります。
- 進み具合はブラウザに自動で保存されます。前の版の保存データも引き継げます（30階の塔の進み具合は、100階の塔に引き伸ばします）。

| `js/data.js` | 英雄17体・敵・塔100階・区域・地方・施設・装備・薬・状態・提案 |
| `js/battle.js` | オート戦闘（英雄の思考・信頼度・恐怖・出血・サボり・薬・命令・提案・MVP）。Node でもシミュレーションできる |

| `js/field.js` | 戦闘の映像（英雄と敵が動く） |
| `js/game.js` | 保存・ガチャ・育成・昇級・記憶・施設・装備・薬・提案・永久ロスト・報酬 |
| `js/ui.js` | 画面の表示と操作 |
| `manifest.webmanifest`, `sw.js`, `icons/` | ホーム画面に追加（PWA）とオフライン対応 |

外部ライブラリ・画像素材は使っていません。
