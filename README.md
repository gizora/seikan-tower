# 星喚の塔（試作版・第2版）

ガチャで英雄を集めて、作戦を決めて塔に挑む、スマホ向けのオート戦闘ゲームです。
プレイヤーは英雄たちを導く「マスター」です。戦闘中、英雄は**それぞれの性格と、マスターへの信頼に合わせて自分で考えて**動きます。プレイヤーが決めるのは**編成と作戦**です。

名前・キャラクター・世界観はすべてオリジナルです。

公開ページ: https://gizora.github.io/seikan-tower/

## 遊び方

1. **待機室**（ホーム）: 英雄たちが暮らす部屋。歩き回ったり、本を読んだり、訓練したり、話したりしている。タップすると話しかけられる（戦闘ごとに1回、信頼度 +6）
2. **召喚**: 💎 召喚石で英雄を呼ぶ（1回 100 / 10回 1,000 で★2以上が1体確定 / 60回までに必ず★3）。すでにいる英雄が出ると ✦ 星の欠片になる
3. **編成**: 5人までのパーティーを組み、前衛・後衛に置く（前衛は狙われやすい）
4. **作戦**: 作戦 / 狙う敵 / 回復の目安 / スキル / 撤退 の5つを決める（戦闘中も変えられる）
5. **塔**: 30階。5階ごとにボス。勝つと経験値・金貨・星の欠片、初クリアでは召喚石ももらえる

### このゲームの決まり
- **永久ロスト**: 塔で倒れた英雄は二度と戻らない。名前は待機室の慰霊碑に刻まれ、仲間たちのマスターへの信頼が下がる。危ないときは「撤退」ボタンか、作戦の「撤退」（1人倒れたら / 危なくなったら）で逃げられる。
- **信頼度**（0〜100）: 45 未満の英雄は、作戦を無視して自分の考えで動くことがある。60 以上で能力 +5%、90 以上で +10%。話す・一緒に勝つ・昇級で上がり、負ける・仲間を失うと下がる。
- **★の昇級（成り上がり）**: 最大レベルになったら、星の欠片で★を上げられる（★1 → ★5）。★が上がると能力と最大レベルが上がり、★3 と ★5 で特性の枠が増える。★1 の英雄も ★5 まで育てられる。
- **特性**（10種類・Lv1〜3）: 怪力・鉄壁・頑丈・俊足・会心・癒し手・吸血・先制・不屈・反撃。英雄はそれぞれ違う特性を持って生まれる。
- **送り出す・合成**: 英雄を故郷へ送り出すと星の欠片がもらえる。そのとき特性を1つ、ほかの英雄に受け継がせられる（同じ特性ならレベルが上がる＝合成）。
- **性格**（5種類）: 忠実 / 勇敢 / 慎重 / 気まぐれ / 仲間思い。同じ作戦でも動き方が違う。

## 起動のしかた

- **PC で試す**: `index.html` をブラウザで開くだけで遊べます。
- **スマホ**: 公開ページを開き、Android（Chrome）は「ホーム画面に追加 / アプリをインストール」、iPhone（Safari）は共有 →「ホーム画面に追加」。一度開くとオフラインでも遊べます。
- 進み具合はブラウザ（localStorage）に自動で保存されます。第1版の保存データはそのまま引き継げます（覚醒は星の欠片に変わります）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目 |
| `js/data.js` | 英雄17体（見た目も）・敵・塔30階・特性・作戦・会話 |
| `js/battle.js` | オート戦闘（英雄の思考・信頼度・特性・ボスの特徴）。Node でもシミュレーションできる |
| `js/sprites.js` | ドット絵をコードで描く（英雄は髪型・服・飾り・武器の組み合わせ、敵は1体ずつ） |
| `js/room.js` | 待機室（キャンバスで描く部屋と、歩き回る英雄） |
| `js/game.js` | 保存・ガチャ・育成・昇級・信頼度・送り出し・永久ロスト・報酬 |
| `js/ui.js` | 画面の表示と操作、戦闘の演出 |
| `manifest.webmanifest`, `sw.js`, `icons/` | ホーム画面に追加（PWA）とオフライン対応 |

外部ライブラリ・画像素材は使っていません（絵はすべてコードで描いています）。
