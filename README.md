# 星喚の塔（試作版・第6版）

滅びかけた世界の「待機室」で、記憶をなくした英雄たちを導き、100階の塔を制覇して世界を救うゲームです。
プレイヤーは英雄たちの「マスター」。ゲームの中で映すのは待機室だけで、建物や英雄をタップしてすべての機能に入ります。
物資を作り、陣地を広げて英雄を支え、作戦と命令で塔を攻略します。

名前・キャラクター・世界観・絵はオリジナルです（絵はすべてコードで描いています）。

公開ページ: https://gizora.github.io/seikan-tower/

## 第6版で変わったこと
- **ログアウト**: 右上の ⏻ を押すと確認が出ます。「ログアウト」で保存してアプリを閉じます（ブラウザが閉じるのを止めたときは「おつかれさまでした」の画面になり、「待機室に戻る」で続けられます）。
- **見た目**: ボタンや枠を、すりガラスの近未来風（半透明の板・ぼかし・細く光る水色と紫の線）にしました。
- **塔**: 1階から100階までを下から積み上げた塔として描きます。開くと今の階まで動き、新しくクリアした階は上から積み上がるように光ります。
- **探索の速さ**: ふつうの速さ（×1）を、英雄と一緒に歩く速さにしました。英雄は先頭のうしろに隊列を組んでついて歩き、遅れた仲間を待ちます。戦闘もゆっくりになり、カメラは一行の近くを追います（×2・×4 にも切り替えられます）。
- **任務は手掛かりで判明**: 塔の中には NPC・石碑のほかに、足跡・書き置き・冒険者の亡骸・壁画が散らばっています。英雄が調べて手掛かりが 2 点（足跡などは 1 点、壁画・石碑・NPC は 2 点）たまると任務が判明します。
- **待機室の名前は変更できません**（始めたときに決まった世界の名前のまま）。
- **物資の生産**: 食料・木材と石材・鉱石・魔石を、畑・石切り場・鉱山で現実の時間に合わせて作ります。英雄は自分の考えで手伝いに行き、人が多いほどたくさんできます。
- **陣地構築**: 城壁を上げると陣地が広がり、物資をためておける量と、生産施設のレベルの上限が上がります。見張り塔を建てると、塔に入ったときの偵察が広がります（Lv3 から手掛かりの場所、Lv5 から魔物の巣がはじめからわかる）。
- **曜日のダンジョン**: 次元の門から、現実の曜日ごとに違うダンジョンに入れます（1日3回まで）。

## 世界
- 待機室の名前（カタカナ5文字ほど・始めたときに決まる・変更不可）が、そのまま滅びかけた世界の名前です。塔の100階を制覇すると世界を救えます。
- 英雄はその世界の人々。何も覚えていませんが、★を上げるたびに記憶がよみがえります。
- 召喚のたびに、名前・見た目・職業・性格・才能・記憶がすべて違う英雄が生まれます。**同じ英雄は二度と出ません**（まれに、手作りの特別な英雄が一度だけ現れます）。

## 待機室（ホーム）
- 城壁に囲まれた敷地を、立体の世界とドット絵の英雄で描いています（光・影・霧・光のにじみ・ミニチュア風のぼかし）。時間帯は現実の時計に合わせて昼・夕方・夜に変わります。
- ドラッグで見回す・ピンチやホイールで寄る・2本指でひねって回す（右下のボタンでも可）。
- **待機室の時間は現実と同じ速さで進みます**。閉じていた間も最大4時間ぶん進み、開くと「留守のあいだに」で起きたことと、できた物資がわかります。
- 英雄は自分の考えで過ごします（訓練所で訓練する・広場で過ごす・宿舎で休む・物資づくりを手伝う・歩き回る）。頭の上のアイコンで、何をしているかがわかります。
- 建物: 🌀 次元の門（塔・曜日のダンジョン・召喚）/ 🛏️ 宿舎（英雄の一覧）/ ⛲ 広場（提案・喧嘩・仲・出来事）/ 🎯 訓練所 / 🗺️ 戦略室（編成と作戦）/ ⚗️ 合成所 / ⚔️ 武器倉庫 / 🧪 錬金場 / 🌾 畑 / 🪵 石切り場 / ⛏️ 鉱山。城壁や見張り塔をタップすると陣地の画面になります。

### 物資
| 物資 | 作る場所 | 使いみち |
|---|---|---|
| 🍞 食料 | 畑 | 英雄が毎分食べる。塔へ出かけるときに1人4つ持っていく。宴会の提案 |
| 🪵 木材と石材 | 石切り場 | 建物のレベル上げ・城壁・見張り塔 |
| 🪨 鉱石 | 鉱山 | 装備づくり・高いレベルの建物・陣地 |
| 🔮 魔石 | 鉱山（少しずつ） | 薬づくり・強い装備・最高レベルの建物 |

- 食料が尽きると英雄は**空腹**になり、訓練しても伸びず、信頼度が少しずつ下がります。食料が足りないまま塔へ行くと「空腹状態、能力値が15%減少」のまま戦います。
- 物資は城壁のレベルで決まる量までためられます（Lv1 で 400、Lv5 で 6000）。いっぱいになると知らせが出ます。
- 塔で勝つと、木材と石材・鉱石（ボスの階や初クリアでは魔石も）を持ち帰ります。

### 曜日のダンジョン
| 曜日 | 場所 | 主な報酬 |
|---|---|---|
| 日 | 黄金の回廊 | 金貨 |
| 月 | 実りの森 | 食料 |
| 火 | 炎の坑道 | 鉱石 |
| 水 | 魔石の泉 | 魔石 |
| 木 | 古代樹の森 | 木材と石材 |
| 金 | 星屑の聖堂 | 星のかけら・召喚石 |
| 土 | 修練の迷宮 | 経験値（2.5倍）と物資を少しずつ |

- 難しさは 初級（3階クリア）/ 中級（25階）/ 上級（55階）/ 超級（85階）。上ほど報酬が多くなります。
- 任務ははじめからわかっています（魔物の巣をすべて潰す）。物資の箱を見つけると報酬が増え、負けても見つけた箱の分は持ち帰れます。倒れた英雄は塔と同じく戻りません。

### 才能と訓練・成長
- 英雄には能力（体力・攻撃・防御・速さ）ごとに才能（— / C / B / A / S）があります。
- 訓練所で訓練すると、才能のある能力が少しずつ伸びます。**才能のない能力（—）は伸びません**。伸ばせる上限は才能と★で決まります。
- 塔の中で戦うと、使った能力が伸びます。

### 仲・喧嘩・殺し合い
- 英雄どうしには仲（-100〜100）があり、性格の相性や一緒に過ごした時間で変わります。
- 仲が悪いと喧嘩が起きます。タップして**仲裁**します（どちらかの味方をする / 二人を叱って仲直りさせる）。
- 仲裁しないまま時間がたつと、けが人が出ます。仲がとても悪いと**殺し合い**になり、英雄が失われます。
- 仲がとても悪い英雄どうしを同じ編成にすると、塔の中で**裏切る**ことがあります。

### 提案
英雄の声は聞こえません。英雄は「〜が〜を提案しています」で、マスターに提案します。受けると信頼度が上がり、断ると少し下がります。

## 塔の中（マスターが見ている映像）
- 階ごとに広いマップがあり、壁・水・草むら（隠れるとダメージが減る）・高台（上から攻撃するとダメージが増え、弓や魔法が遠くまで届く）があります。
- **任務は階ごとに違い、最初はわかりません**。英雄が手掛かりを調べると判明します（討伐・回収・護衛・探索・生存・主の討伐）。任務を果たすと出口が開き、出口にたどり着けば勝ちです。
- 英雄は隊列を組んで一緒に探索し、戦い、危なければ逃げます。英雄の一覧で、誰が何をしているか（探索・同行・調査・攻撃・回復・防御・逃走・**サボり**など）がわかります。
- 英雄をタップすると命令できます: ⚔️ 狙え / ✦ スキル / 🛡️ 守れ / 📍 ここへ / 💨 逃げろ。「指示」をオンにすると、地面をタップして全員の行き先を決められます。信頼度が低い英雄は従わないことがあります。
- 様子はメッセージでわかります（「〜が恐怖状態、能力値が30%減少」「〜が出血状態、体力が減少中」など）。
- 最後に **MVP** と、レベルや能力が上がった英雄、持ち帰った物資がわかります。倒れた英雄は二度と戻りません。

## 画面の向き
縦でも横でも遊べます。横にすると、塔の中では英雄の一覧が左に並びます。

## 起動のしかた
- **PC で試す**: `index.html` をブラウザで開くだけで遊べます（WebGL が使えるブラウザ）。
- **スマホ**: 公開ページを開き、ホーム画面に追加するとアプリのように遊べます（オフラインでも可）。ネットにつながっていれば、開くたびに最新版になります。
- 進み具合はブラウザに自動で保存されます。前の版の保存データも引き継げます（第5版からは、畑と石切り場が建ち、物資がはじめの量で始まります）。

## 決めたこと（判断した内容）
- ログアウトは「確認 → 保存 → アプリを閉じる」。ふつうのブラウザのタブはスクリプトから閉じられないことが多いので、そのときは「おつかれさまでした」の画面を出します。
- 物資は 食料・木材と石材・鉱石・魔石 の4種類。陣地構築は「待機室の陣地（城壁と見張り塔）を広げる」形にしました。
- 曜日のダンジョンは、端末の時計の曜日で決まります。回数は日付が変わると3回に戻ります。

| `js/battle.js` | 塔の中のしくみ（マップ・経路・手掛かりと任務・隊列・英雄の考え・戦闘・命令・提案・裏切り・偵察・MVP）。画面に依存せず Node でも動く |
| `js/game.js` | 保存・召喚・育成・待機室の時間・訓練・物資の生産・陣地・曜日のダンジョン・仲・喧嘩・施設・報酬 |
| `js/sprites.js` | ドット絵をコードで描く（英雄は 32×64 ドット・斜め前から見た姿・ポーズつき） |
| `js/world3d.js` | 立体の世界の共通部分（光・カメラ・後処理・ドット絵の板・pixelfx のエフェクト） |
| `js/room.js` | 待機室（立体）。城壁のレベルで広がる陣地・見張り塔・生産施設 |
| `js/field.js` | 塔の中の映像（立体）。手掛かり・物資の箱 |
| `js/ui.js` | 画面の表示と操作 |
